# 🔑 Cantilever Cybersecurity Internship — Task 2

## Keylogger Security Demonstration

A Python-based **Keylogger Security Demonstration** that illustrates keyboard event detection, timestamp logging, special key identification, event counting, and local report generation in a controlled application environment.

This project was developed as part of the **Cantilever Cybersecurity Internship**.

> ⚠️ **Security Notice:** This implementation is designed strictly as a controlled educational demonstration. It captures keyboard input only within the application's visible test environment and does not perform system-wide monitoring, hidden surveillance, credential theft, or network transmission.

---

# 🎯 Objective

The objective of this task is to demonstrate the fundamental concepts behind keyboard event monitoring using Python.

The application provides a visible test interface where users can:

- Start keyboard event logging.
- Enter test keyboard input.
- Detect keyboard events.
- Identify normal keyboard keys.
- Identify special keyboard keys.
- Record timestamps for keyboard events.
- Count the number of recorded events.
- Stop keyboard event logging.
- Generate a local text report.

The project demonstrates how keyboard events can be processed and recorded while maintaining a controlled and transparent testing environment.

---

# ✨ Features

### ⌨️ Keyboard Event Detection

The application detects keyboard events entered through its controlled test interface.

Example:

```text
[2026-08-29 12:05:02] c
[2026-08-29 12:05:03] a
[2026-08-29 12:05:03] n
[2026-08-29 12:05:03] t
```
